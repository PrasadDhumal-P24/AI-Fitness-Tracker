# 🏋️ AI Fitness Tracker

A modern fitness tracking web application built with React and AI integration to help users track workouts, calories, and fitness progress.

## 🚀 Features

- 🏋️ Track workouts
- 🔥 Track calories
- 📊 Monitor fitness progress
- 🤖 AI-powered fitness assistance
- 💾 Persistent data using LocalStorage
- 📱 Responsive user interface
- ⚡ Fast and interactive React UI

## 🛠️ Tech Stack

- React
- JavaScript
- HTML
- CSS
- AI Integration
- LocalStorage
